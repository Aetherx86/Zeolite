# Zeolite

샌드박스 워크로드를 위한 분산 런타임 (A Distributed Runtime for Sandboxed Workloads)

샌드박스 격리 워크로드를 안전하게 실행하기 위한 분산 런타임 시스템입니다. 노드 클러스터는 Raft 합의 알고리즘을 통해 배포 상태를 동기화하며, 각 워크로드를 세 가지 격리 계층(결정론적 JIT, 계량된 WebAssembly 샌드박스, 하드웨어 가상화 마이크로 VM) 중 하나에서 실행합니다.

[English Documentation](README.md)

미세한 격리 케이지들로 이루어진 광물 제올라이트(Zeolite)처럼, 하나의 견고한 구조 내에서 수많은 소형 워크로드를 철저히 격리하여 구동합니다.

```text
                   HTTP gateway: deploy, execute, invoke, webhooks, boot
                                          |
            +-----------------------------v------------------------------+
            |  zeolite-raft     합의 및 지속성 복제 로그                  |
            |                   State + Command -> New State + Result    |
            +----------+------------------+------------------+-----------+
                       |                  |                  |
            +----------v-----+  +---------v-------+  +-------v----------+
            |  zeolite-jit   |  |  zeolite-faas   |  |  zeolite-vmm     |
            |  Zel 언어      |  |  Wasm 함수      |  |  KVM / HVF       |
            |  복제 실행     |  |  요청당 격리    |  |  마이크로 VM     |
            +----------------+  +-----------------+  +------------------+
```

## 실행 격리 계층

- **결정론적 JIT (zeolite-jit)**: 부동 소수점이나 비결정적 시스템 콜 없이 순수 함수형 Zel 언어를 Cranelift를 통해 네이티브 머신 코드로 JIT 컴파일하여 복제 상태 머신 상에서 실행합니다.
- **WASM 샌드박스 (zeolite-faas)**: 메모리 및 인스트럭션 실행량이 엄격히 계량(metered)되는 WebAssembly 인스턴스로 요청 단위 서버리스 함수를 초고속 디스패치합니다.
- **마이크로 VM (zeolite-vmm)**: Linux KVM 또는 macOS Hypervisor.framework 기반 초소형 하드웨어 가상 머신으로 완전한 OS 커널을 격리 실행합니다.

## 성능 측정치

Apple Silicon 디버그 빌드 기준:

| 작업 | 시간 |
| --- | --- |
| WASM 인스턴스 생성 (중앙값) | 16 마이크로초 |
| 소형 AArch64 페이로드를 포함한 마이크로 VM 부팅 후 종료 | 약 60 마이크로초 |

## 버전 관리

버그 수정 및 보안 패치는 `0.0.X`, 신규 기능 및 플랫폼 지원 추가는 `0.X.0`을 증가시킵니다. 세부 사항은 [CHANGELOG.md](CHANGELOG.md)를 참조하십시오.

## 0.2.0 변경 사항

- **리더십 이전**: `POST /v1/leadership/transfer`에 `{"to": 2}`를 보내면 리더가 쓰기를 멈추고 대상 노드의 로그를 최신으로 맞춘 뒤, 새 `TimeoutNow` 메시지로 즉시 선거를 시작하게 합니다. 대상이 리더가 되면 응답이 돌아오며 보통 한 텀이 증가합니다. 선거 타임아웃 안에 끝나지 않으면 이전은 취소되고 기존 리더가 계속 쓰기를 받습니다. 모든 노드가 0.2.0 이상이어야 합니다.
- **데이터 디렉터리 점검**: `zeolite inspect DIR [--json]`은 파일을 전혀 바꾸지 않고 WAL 크기, 손상된 꼬리 바이트, 하드 스테이트, 스냅샷 정보, 커밋된 명령 수를 보여 주며, 커밋된 로그를 스냅샷 위에 재실행해 저장된 커밋 인덱스 시점의 상태 다이제스트를 계산합니다. 같은 커밋 인덱스에서 멈춘 복제본은 같은 다이제스트를 보고합니다.
- **Zel 실행 결과 JSON 출력과 백엔드 비교**: `zeolite zel --json`은 결과 또는 트랩, 사용한 가스, 백엔드, 최종 메모리의 SHA-256을 출력합니다. `--compare`는 인터프리터와 JIT에서 같은 호출을 실행하고 결과, 가스, 메모리가 모두 일치하지 않으면 0이 아닌 종료 코드를 돌려줍니다.
- **테스트**: 리더십 이전을 섞은 결정론적 장애 주입 시뮬레이션, 실제 노드 간 이전 테스트, 두 백엔드의 가스 계량이 정확함을 확인하는 속성 테스트를 추가했습니다.
- **보안**: wasmtime 48.0.10과 Cranelift 0.135.10으로 올려 RUSTSEC-2026-0566부터 0573까지를 해결했습니다.
